## Summary

Adds an exportable remediation backlog, configuration upgrade compatibility coverage, an explicit release artifact retention policy, and a published/tested runtime matrix.

## Changes

- Add `gasguard backlog <report.json>` with CSV, JSON, and Markdown exports, stable finding IDs, severity ordering, and CSV formula-injection protection.
- Add in-memory v1-to-v2 config migration compatibility tests for legacy aliases, inheritance, unchanged current configs, and rejected future versions.
- Define 90-day retention for temporary release workflow artifacts; published GitHub Release assets remain available until the release is removed.
- Publish Node.js 22/24 and Rust stable support, and add a CI matrix that builds, tests, and smoke-tests the CLI on both Node versions.
- Repair CLI scan/build blockers so the runtime compatibility job exercises the actual CLI.
