## Summary

Implements backward-compatible CLI configuration migrations, signed multi-platform CLI releases, and historical scan report comparisons.

## Changes

- Migrate legacy top-level `includePatterns`, `excludePatterns`, and `outputFormat` config keys in memory; reject invalid and unsupported future schema versions.
- Build standalone CLI executables for Linux x64, macOS x64/arm64, and Windows x64, with Sigstore keyless signature bundles.
- Add `gasguard compare <baseline.json> <current.json>` with text and JSON reports, stable finding matching, and optional file output.
- Repair existing CLI compilation and scan-discovery blockers required to build and run the standalone CLI.
- Document config migration behavior, comparison inputs, release dependencies, and signature verification.

## Verification

- `node_modules/.bin/jest packages/cli/src --runInBand` (24 tests passed)
- `node_modules/.bin/tsc -p packages/cli/tsconfig.json --noEmit`
- Release workflow YAML validation with all four platform targets
- Built and ran a standalone macOS x64 executable with `gasguard --help`

## Dependencies

Release builds use GitHub Actions runners and artifacts, Node.js 22, `@yao-pkg/pkg` 6.23.0, GitHub OIDC, and Sigstore. The comparison command consumes saved GasGuard JSON scan reports.
